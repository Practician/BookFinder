# BookFinder

**BookFinder** — это веб-приложение для удобного поиска и скачивания книг из различных открытых источников. Программа объединяет несколько парсеров, позволяя искать литературу в одном интерфейсе.

## Основные возможности
- **Мультипоиск**: Поиск книг одновременно по нескольким источникам:
  - Anna's Archive
  - Flibusta (через прокси/зеркала)
  - Librain
  - И другие.
- **Удобный интерфейс**: Чистый и современный веб-интерфейс для отображения результатов поиска.
- **Автоматизация**: Готовые скрипты для быстрой установки и запуска на Windows.

## Технологический стек
- **Backend**: Node.js, Express
- **Parsing**: Puppeteer (для работы с динамическим контентом)
- **Frontend**: HTML5, Vanilla CSS, JavaScript

## Установка и запуск

### Требования
- Установленный [Node.js](https://nodejs.org/)

### Быстрый старт (Windows)
1. Склонируйте репозиторий или скачайте архив.
2. Запустите файл `1_установить_на_новом_пк.bat` для установки всех необходимых зависимостей.
3. Для запуска программы используйте `2_запустить_поиск.bat`.
4. Откройте браузер по адресу `http://localhost:3000`.

# BookFinder (English)

**BookFinder** is a web application for convenient searching and downloading of books from various open sources. The program integrates several parsers, allowing you to search for literature in a single interface.

## Key Features
- **Multi-search**: Search for books across multiple sources simultaneously:
  - Anna's Archive
  - Flibusta (via proxies/mirrors)
  - Librain
  - And others.
- **User-friendly Interface**: A clean and modern web UI for displaying search results.
- **Automation**: Ready-to-use scripts for quick installation and launch on Windows.

## Tech Stack
- **Backend**: Node.js, Express
- **Parsing**: Puppeteer (for handling dynamic content)
- **Frontend**: HTML5, Vanilla CSS, JavaScript

## Installation and Setup

### Requirements
- [Node.js](https://nodejs.org/) installed

### Quick Start (Windows)
1. Clone the repository or download the archive.
2. Run `1_установить_на_новом_пк.bat` to install all necessary dependencies.
3. Use `2_запустить_поиск.bat` to start the application.
4. Open your browser at `http://localhost:3000`.
